Facts first: compact cards, automatic scrolling, preserved category position, and 921 sourced discoveries in English and Spanish. Includes legacy-console and Minecraft spinoff topics, a searchable/exportable database, and connected reference guides.

Android 8+ / Windows 10 and 11, 64-bit. Installed apps open the fact feed directly and check for new GitHub releases. Update opens the official installer; operating-system installation approval is required.

Android v0.7 is the first APK signed with the permanent Blockwise release key. Earlier debug builds used a different signing identity. Export your bookmarks in Settings before moving from a debug build; Android may require removing the old debug app first. Future release-key builds can update in place.

These are independent direct-download apps, not Google Play-verified or Microsoft-signed distributions. Android Play Protect or Windows SmartScreen can display warnings; this release does not bypass those protections. You can also use the web version without installing an executable.

The private API connection is optional and configured in Settings using your public Cloudflare website URL. Offline reading and local bookmarks work without a server connection.
